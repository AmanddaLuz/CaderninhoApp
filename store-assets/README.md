# Play Store assets

- `icon-512.png`: ícone da ficha, 512 x 512, RGB e sem transparência.
- `feature-graphic-1024x500.png`: imagem de destaque, 1024 x 500.
- `screenshots/`: adicionar capturas de celular sem dados pessoais reais.

Antes do upload, confira os arquivos no preview da Play Console. As capturas
devem usar dados fictícios e representar Home, clientes, detalhe/cobrança e
resumo.
