# Privacy policy hosting

- The application source repository must be private.
- The public privacy policy lives in the dedicated
  `AmanddaLuz/caderninho-privacy` repository.
- The canonical public URL is
  `https://amanddaluz.github.io/caderninho-privacy/`.
- Never link public app surfaces or Play Console metadata back to the private
  source repository.
- Publish and validate the standalone policy before changing repository
  visibility so released app versions retain a working privacy URL.
